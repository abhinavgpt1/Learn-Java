- Object-Oriented Programming (OOP): A programming paradigm that organizes software around objects, which encapsulate data (state) and methods (behavior), just like real-world entities using core principles such as encapsulation, abstraction, inheritance, and polymorphism.

- Class: A class is a blueprint used to create objects that share common properties and behavior.

- Object: An object is a runtime instance of a class that encapsulates state (fields/attributes) and behavior (methods/operations).

- Encapsulation: The OOP principle of bundling data and the methods as a single-unit, while restricting direct access to the objects memebers.

- Abstraction: The OOP principle of hiding implementation details and exposing only the essential functionality to the user.

- Inheritance: A mechanism by which one class (subclass/child) acquires the properties and behaviors of another class (superclass/parent) and can extend or customize them. It establishes an "IS-A" relationship.

- Polymorphism: The ability of an object, method, or reference to take multiple forms and behave differently depending on the context.
